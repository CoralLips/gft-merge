# GFT-Merge

## 让上下文在 AI 编程会话之间流动。

**把 Claude Code 和 Codex 的会话拉进一个池子，再在任一工具里开一个新会话，上下文已经带在里面。**

你在一个 Claude Code 会话里定方案，在 Codex 里写代码，又在另一个会话里排查问题。每次交接都得手动复制粘贴。GFT-Merge 读取你本机的会话，让你把有用的几段合在一起，然后开一个新会话、把它们作为第一条消息带进去，AI 就能接着往下干。

在你自己的电脑上运行，在浏览器里打开。和 [GFT-Map](https://github.com/CoralLips/gft-map) 是同一系列的工具。

## 开始

需要 **Node.js 22 以上**，以及下面至少一个：

- **Claude 桌面应用里的 Claude Code**，已登录。新建的 Claude 会话要通过桌面应用自己的 `claude://` 链接导入，所以必须有桌面应用才能看到。
- **Codex**，桌面应用或命令行都可以，已登录。装了 Codex 桌面应用的话，新会话也会在里面打开。

然后运行：

```sh
npx gft-merge
```

浏览器会打开 `http://127.0.0.1:4319`。之后随时再运行一次即可，已经在跑的服务会直接复用。

## 怎么用

页面分上下两半。上面每个工具一栏，列出最近 30 天的会话；下面左边是池子列表，右边是选中池子的工作区。所有操作都靠拖。

| 想做什么               | 怎么做                                                               |
| ---------------------- | -------------------------------------------------------------------- |
| 把会话放进池子         | 从上面的工具栏拖进工作区，它就成了一个球                             |
| 合并几个会话           | 把一个球拖到另一个球上，任意两个球都能融合                           |
| 带着这些上下文开新会话 | 把球往上拖到某个工具的栏上，就在那里新建会话，名为「merge · 池子名」 |
| 把大球变小             | 点一下球，用模型压缩（见下文）                                       |
| 看球里有什么           | 鼠标悬停在球下方的名字上；从列表里把某个会话拖出去就能拆开           |
| 搬走或移出             | 把球拖到左边另一个池子上就搬过去；拖出工作区就移出池子               |

**球里的数字**是 token 数。单个会话的球显示这个会话本身的上下文大小，直接读自工具的记录；融合或压缩过的球显示往上拖时要送出去的量，由本地分词器数出来，前面带 ≈。

**压缩**会把球的内容发给 **设置 → 处理工具** 里选的工具和模型，用结果替换原内容。压缩中球的虚线圈会转，名字处显示“压缩中…”。压完的球不能再拆，但可以继续往上融合新的会话，也可以再压。压缩没完成时往上拖，送出去的是原文。

**新会话的第一条消息**包含球里每个会话的原话（你说的话和 AI 每轮的最终回答，不含工具输出），并请 AI 先简要汇报它的理解（这些会话在做什么、进展到哪、定了什么、没定什么、下一步做什么），然后等你的指示。这一轮是真对话，所以新会话排在工具列表最上面。Codex 那边页面立刻返回，回复结束后在 Codex 里打开；Claude 那边要等回复结束（几秒到一分钟左右），然后在 Claude 桌面应用里打开。

**为什么只做新建：** Codex 会话在 Codex 桌面应用里开着时，Codex 不让别的程序往里写；Claude 桌面应用显示的是它自己保存的会话内容，别的程序写进去的消息它不显示。两条路都靠不住，所以 GFT-Merge 只新建会话。

## 数据去哪了

- GFT-Merge 读取你本机 Claude Code 和 Codex 的会话文件，不修改它们，也不装钩子、不改两家工具的任何设置。
- 池子存在你电脑上的 `~/.gft-merge/`（可用 `GFT_MERGE_HOME` 改位置）。
- 只有两种情况会调用模型，都由你触发：往上拖新建会话（在那个工具里、用你的账号额度），以及压缩（向处理工具发一次请求，用你的账号额度）。
- 不需要 GFT 账号，不上云。

## 命令

```sh
npx gft-merge          # 打开页面，需要时自动启动服务
npx gft-merge stop     # 停止服务
npx gft-merge status   # 查看是否在运行、数据在哪
```

加 `--port <端口>` 可以换端口。
