# GFT-Merge

本地小工具：上面是各工具的会话，下面是池子。往下拖合并，往上拖到某个工具区就在那里新建会话。

## 打开

在 GFT-Merge 目录运行：

```bash
node cli.mjs open
```

然后告诉用户页面地址（默认 `http://127.0.0.1:4319`）。不要替用户拖动或送内容。

## 往上拖时

在那个工具里新建会话，池子内容是第一条消息，AI 先简要汇报它的理解，然后等用户指示。不装钩子、不改工具配置。Claude 的新会话发完后用 `claude://resume` 链接导入桌面端并打开。不支持发进已有会话（Codex 开着的会话拒绝外部写入，Claude 桌面端不显示外部写入）。

## 边界

- 只新建会话；不往已有会话里写，不删除、不改写任何会话。
- 送的是精简原话；内容可能很长。用户在页面上点球才会压缩，压缩会调用模型、花用户的额度，不要替用户触发。
- 数据只在本机 `~/.gft-merge/`。
